# Coin Tracker 🚀

Just a simple, clean crypto tracker I built to keep an eye on prices without all the clutter of major exchanges.

It's built with **Next.js 15** and uses **Lightweight Charts** for the candles (because they look great and are super fast). I also threw in some real-time data fetching so you don't have to mash the refresh button.

### What it does right now:
- 📊 **Live Charts:** Clean candlestick charts that actually look good.
- ⚡ **Real-time Updates:** Prices update automatically.
- 📰 **News Feed:** Pulls in the latest crypto news so you can see why everything is suddenly crashing (or mooning).
- 🌓 **Dark Mode:** Needs to be there, obviously.

### Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lightweight Charts
- Lucide Icons

### Running it locally
If you want to play around with it:

```bash
npm install
npm run dev
```

That's pretty much it. I'm planning to add more stuff like portfolio tracking and wallet connection soon.
